# Image assets

Drop the following files here so they render in the project `README.md`.
Filenames must match exactly (case-sensitive).

| File              | Used in                | Suggested content                                              | Recommended size |
|-------------------|------------------------|----------------------------------------------------------------|------------------|
| `logo.png`        | Header                 | Trailsafe logo (transparent PNG)                               | ~320px wide      |
| `map-preview.png` | Header hero            | HA map with several Trailsafe members + accuracy circles       | ~1400px wide     |
| `config-flow.png` | Configuration > Add    | The integration setup dialog (Server URL + API Key fields)     | ~900px wide      |
| `map-card.png`    | Showing trackers       | A dashboard **Map** card showing the trackers                  | ~1400px wide     |

## Tips

- Export at **2×** the display width (the README scales them down), so they
  stay crisp on high-DPI screens.
- Use **PNG** for screenshots and the logo. A transparent background on the
  logo looks best in both light and dark GitHub themes.
- Blur or crop out any real names, avatars, or precise home coordinates
  before publishing.
- Keep each file under ~500 KB if possible (run them through an optimizer
  like `pngquant` or tinypng) to keep the repo lightweight.
